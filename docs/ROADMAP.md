# KINORYX roadmap

## v0.1, pre-alpha foundation

- One GitHub monorepo with independent engine and dashboard.
- Python packaging and local CLI.
- Synthetic deterministic demonstration.
- Canonical starter CSV ingestion and zero-phase low-pass filtering.
- Exploratory peak candidates with prominent UNVALIDATED labeling.
- Local Plotly/Dash visualization.
- MIT code license, privacy boundaries, contributor documentation and CI.

## Next scientific milestone

- Acquire or legally reuse recordings with independently annotated reference events.
- Establish channel metadata, unit and coordinate-frame adapters, starting with Xsens exports.
- Define defensible IC and toe-off candidate generation and cycle validation.
- Evaluate timing error and omissions across walking conditions and pathological gait.
- Support uncertainty, manual correction and transparent versioned analysis.

## Later product milestones

- Reproducible cycle-normalized plots, bilateral metrics and report exports.
- Multi-format sensor adapters, accessible UI and packaged desktop builds.
- Secure and optionally hosted interface if a valid privacy and support model is demonstrated.

No unvalidated detection output should be marketed as a diagnostic or clinically established assessment.
